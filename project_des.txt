==========================================================================
                       AI VIDEO ASSISTANT WITH RAG
==========================================================================

OVERVIEW
--------------------------------------------------------------------------
A free, fully local AI-powered meeting and video intelligence assistant.
It transcribes any audio/video (YouTube link or local file), extracts
structured summaries and action items, and lets users ask questions about
the content using Retrieval-Augmented Generation (RAG).
No paid APIs. No subscriptions.


PROBLEM IT SOLVES
--------------------------------------------------------------------------
- Meetings generate huge spoken information that is lost after the call.
- No notes, forgotten action items, no way to search past discussions.
- Tools like Otter.ai and Fireflies cost $20-40/month.
- This project gives the same core value FREE, running locally,
  with native Hindi and Hinglish support.

PHASE 2 : RAG (RETRIEVAL-AUGMENTED GENERATION)
--------------------------------------------------------------------------

  A) INDEXING (done once per video)

     Transcript
         |
         v
     Split into chunks
     (500 characters, 50 overlap)
         |
         v
     Embeddings
     (HuggingFace all-MiniLM-L6-v2, local CPU)
         |
         v
     +------------------------------+
     |  ChromaDB (local, persistent)|
     +------------------------------+


  B) QUESTION ANSWERING (every user question)

     User Question
         |
         v
     Embed the question
         |
         v
     +------------------------------+
     |  ChromaDB similarity search  |
     |  retrieve top k = 4 chunks   |
     +------------------------------+
         |  relevant transcript chunks
         v
     +------------------------------+
     |  LCEL Q&A Chain (Groq LPU)   |
     |  answers ONLY from the       |
     |  retrieved chunks            |
     +------------------------------+
         |
         v
     Grounded Answer (no hallucination)


  WITHOUT RAG vs WITH RAG

     Without RAG : LLM has no meeting context
                   -> says "I don't know" or hallucinates
     With RAG    : ChromaDB fetches exact transcript parts
                   -> LLM answers strictly from that context


TECH STACK
--------------------------------------------------------------------------
+----------------------+-------------------------------------------+
| Layer                | Technology                                |
+----------------------+-------------------------------------------+
| Audio Extraction     | yt-dlp, ffmpeg                            |
| Speech-to-Text       | OpenAI Whisper (local, CPU)               |
| LLM & Orchestration  | LangChain (LCEL) + Groq API (Llama 3.3 70B)|
| Vector Store         | ChromaDB (local, persistent)              |
| Embeddings           | HuggingFace all-MiniLM-L6-v2 (local, CPU) |
| Export               | fpdf2 (PDF meeting notes)                 |
| UI                   | Streamlit + Standalone Web Studio         |
+----------------------+-------------------------------------------+
